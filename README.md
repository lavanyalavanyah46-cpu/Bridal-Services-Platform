# Bridal Services Platform
A responsive frontend demo for a bridal services marketplace.

## Features
- Home page and bridal inspiration
- Service categories
- Artist listing with category, price, rating and location filters
- Artist profile cards with portfolio-style display
- Appointment booking form
- Reviews/ratings display
- Login/Register demo modal
- Responsive mobile layout

## Run
Open `index.html` in any modern browser.

## Note
This is a frontend demo. Login, booking persistence, payments and database functionality require a backend.
